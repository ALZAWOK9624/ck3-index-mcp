# Fixtures

`common/` contains only the generic Clausewitz plaintext subset used for
differential checks. The inputs deliberately cover nested objects, arrays, a
mixed container, a container header, quoted and UTF-8 scalars, variables, and
all supported comparison operators.

These files are inputs, not evidence that ck3-index must copy every Jomini
interpretation. In particular, the oracle does not define CK3 source positions,
error recovery, comments, or GUI grammar.

`golden/` contains output generated by the pinned Jomini 0.35.0 binary from the
matching `common/` input. The CLI integration test checks these files byte for
byte. Regenerate them only with the oracle binary after intentionally changing
the schema, dependency pin, or fixture; do not derive or hand-write replacement
output and label it as Jomini evidence.
